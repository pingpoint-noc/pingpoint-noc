Register New Monitored Target

Every registered target is watched by ping (ICMP) right away: latency, loss and up/down alerts need nothing else, which is also how to watch a router that offers no SNMP. For SNMP metrics, add the device with python -m tools.add_device and a credential profile. Pick the role that matches the device: only a router / gateway sits at the top of the topology map.

Maintenance

During a window the matching alerts are still evaluated, recorded and shown (marked In maintenance), but no notification is sent. If an alert is still firing when the window ends, it is announced then. Times are in {{ tz }}; when the clocks go back, a time that happens twice means its first occurrence.
